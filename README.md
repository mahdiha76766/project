# Next.js Shop Architecture

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Create `.env.local` and set:
   ```env
   MONGODB_URI=mongodb://127.0.0.1:27017/shop_db
   ```
3. Run project:
   ```bash
   npm run dev
   ```
4. Seed categories:
   ```bash
   npm run seed
   ```

## Folders

- `app`
- `components`
- `lib`
- `models`
- `server`
